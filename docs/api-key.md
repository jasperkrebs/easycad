# Connecting the AI (your Claude API key)

The **Chat** tab talks to Claude with **your own Claude API key**. The key is never in the
website or the repo. There are two ways to connect, and you can switch any time in
**Chat → AI settings**:

| | **Password** (your own proxy) | **Key on this device** |
|---|---|---|
| Setup | Once, about 15 minutes (a free Cloudflare account and four GitHub secrets) | About 1 minute, on each device |
| On a new phone or computer | Type the password | Paste the key |
| Where the key lives | In Cloudflare, as an encrypted secret | In that browser only |
| Who can use your AI | Whoever knows the password | Whoever uses that browser |

**Recommendation:** try it today with *key on this device*, and set up the password when you
want it on every device without copying the key around.

Everything else (sliders, templates, G-code, STL) works without any of this and never uses the AI.

## 1. Get a key (needed for both)

1. **Sign in to the Claude Console:** <https://platform.claude.com>.
   - This is separate from the Claude app and your Claude subscription. API usage is
     pay-as-you-go and **not included in Claude Pro/Max**.
2. **Add credits:** <https://platform.claude.com/settings/billing>. Start small ($5–$20) and leave
   auto-reload off at first.
3. **Set a monthly spend limit** (Console → Settings → Limits). This is the real safety net: even
   if a password leaks, spending stops at the limit.
4. **Create the key:** <https://platform.claude.com/settings/keys> → **Create key**, name it
   `EasyCAD`.
5. **Copy it right away** (it starts with `sk-ant-` and is shown only once) into your password
   manager.

**Never paste the key or the password into a chat** (with Claude or anyone), a file or an issue.

## 2a. Password: your own proxy (for every day)

The proxy is a tiny program in your own free Cloudflare account (`agent-proxy/`, about 150
lines). It keeps the key, checks your password, and passes requests on to Claude. GitHub sets it
up for you; you only create the accounts and enter the secrets.

1. **Cloudflare account** (free): <https://dash.cloudflare.com/sign-up>.
2. **Open "Workers & Pages" once** in the Cloudflare dashboard. The first time, it asks you to
   choose a `workers.dev` subdomain (any name). The proxy's address will be
   `https://easycad-agent.<that-name>.workers.dev`.
3. **API token for GitHub:** My Profile → API Tokens → **Create Token** → use the template
   **"Edit Cloudflare Workers"** → select your account → Continue → Create. Copy the token.
4. **Account ID:** on the Workers & Pages overview page (right side, "Account ID"). Copy it.
5. **Pick a password:** long and random, e.g. 20+ characters generated by your password manager.
   You'll type it once on each device.
6. **Put four secrets into GitHub:** the repo → **Settings → Secrets and variables → Actions →
   New repository secret**, one at a time:

   | Name | Value |
   |---|---|
   | `CLOUDFLARE_API_TOKEN` | the token from step 3 |
   | `CLOUDFLARE_ACCOUNT_ID` | the ID from step 4 |
   | `ANTHROPIC_API_KEY` | your Claude API key (`sk-ant-…`) |
   | `EASYCAD_PASSWORD` | your password from step 5 |

   GitHub keeps secrets encrypted and never shows them again, not even in logs.
7. **Deploy:** the repo → **Actions → CI → Run workflow** (on the default branch). The job
   "AI proxy" sets up the proxy and gives the website its address; when it's done, its summary
   says "The AI proxy is live at …".
8. **In the app:** Chat → AI settings → **My EasyCAD proxy, with a password** → enter the password
   → **Save**. It should say "accepted by the proxy". The address is filled in already.

To **change the password** or **replace the key**, update the GitHub secret and run the workflow
again (step 7).

## 2b. Key on this device (quick start)

Chat → AI settings → **My API key, stored on this device** → paste the key → **Save**. It checks
the key without spending anything. The key is stored only in that browser and sent only to
Anthropic's API (`api.anthropic.com`). **Forget** removes it.

## Who can use it?

- **The website is public** (free GitHub Pages sites always are), but **it holds no secret**.
  Without your password or key, nobody can use the AI. Anyone with the link can use the rest of
  the app, like any public website, and the code is public anyway because the repo is.
- **The proxy** answers only this repo's website (and a local test server), only with the right
  password, only for EasyCAD's three models, with a cap on the size of each request. A wrong
  password gets a slow "no".
- **Your spend limit** in the Console caps the damage if a password ever leaks; then change it
  (step 7 above).
- A fully private website (login before the app even loads) is possible later with Cloudflare
  Access; it adds an account login, not more safety for the key.

Rough costs with Sonnet 5.5 at medium effort (estimates):

- **A small change** ("make it taller", "add a setting for the wall"): about **$0.01–0.05**.
- **A new project** (it writes, runs, looks at the result, fixes): about **$0.05–0.25**.
- **The same with Opus 5.5:** about twice that.
- **Moving sliders, exporting, previews and G-code:** free.

The chat shows the cost of each answer and this month's total on this device. These are
estimates; the Console's **Usage** page has the exact numbers.

### How the app keeps it cheap

- **Caching:** the instructions, the language guide and the list of steps are identical on every
  request, so after the first message they cost a tenth of the normal price. The conversation is
  cached as it grows.
- **Compact feedback:** after each change the AI gets the run result as a few lines of text
  (problems, steps, settings, size, print numbers), and a picture only when it asks for one
  (about as much as 800 words).
- **You choose the effort:** low for quick edits, medium by default, high for hard new projects.
- **Start a new chat** for a new topic: the project itself (its recipe and notes) carries what
  matters, so old messages don't need to come along.

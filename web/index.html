      Print estimate

        One continuous vase-mode spiral: the first turn climbs from the bed while extrusion ramps up, and a flat cap turn closes the rim. Walls only for now; a solid bottom comes with the G-code. Volumes use EasyGCode's bead model, (w − h)·h + π·(h/2)². G-code export arrives in Phase 1b, once it's tested against EasyGCode's output.

        About this build

        Phase 1a: projects are recipes. The Rust engine runs them as WebAssembly in a background worker, and three.js draws on the GPU. Next: real G-code for the P1P and the pellet printer (1b), then the agent (Phase 2).

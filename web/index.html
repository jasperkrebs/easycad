Print estimate

    One continuous vase-mode spiral: the first revolution climbs from the bed while extrusion ramps up, and a flat cap revolution closes the rim. Volumes use EasyGCode's bead model, (w − h)·h + π·(h/2)². G-code export arrives in Phase 1, once it is tested against EasyGCode's output.

    About this build

    Phase 0 is the walking skeleton: the Rust engine runs as WebAssembly in a background worker, and three.js draws on the GPU. Next is Phase 1: project files with their own settings window, and real G-code.

# Robot prints

Packages for the KUKA KR50 pellet cell of the SPHR handover (`SPHR_Full_Print_Handover-2/`),
made with EasyCAD, each laid out like the handover: its programs (`.SRC`, `.DAT`, `.zip`), an
animated simulation in the handover's viewer, the simulation's checks, and a `HANDOVER.md`.

|---|---|
| `Straight_2_Upright/` | the owner's `straight-2` Thread pendant, nozzle always upright: whole print and a 40 mm test |

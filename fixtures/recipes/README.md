# Test recipes

Recipes the engine's tests run (`crates/core/src/*_tests.rs`) that aren't offered as templates in
the app: the early demo shapes (twisted vase, ribbed cylinder, star bowl, cut cylinder, turned
vase) and EasyGCode's spoon (golden-tested against EasyGCode's own G-code). They keep the steps
they use covered. The app's templates are in `web/templates/`.
